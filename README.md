# Lampa Cinematic Screensaver

Бесплатный плагин **видеозаставки 4K без звука** для Lampa — в первую очередь рассчитан на телевизоры Samsung Tizen. Интегрируется со **встроенным механизмом Screensaver Lampa**, а не запускает таймер поверх видеоплеера.

## Ссылка для установки

Прямая ссылка на JS-плагин:

```text
https://raw.githubusercontent.com/DoubleGGameRR/Lampa-Cinematic-Screensaver/main/plugin.js
```

Откройте **Lampa → Настройки → Расширения / Плагины → Добавить плагин**, вставьте эту ссылку и перезапустите Lampa. Затем откройте **Настройки → Cinematic Screensaver**.

В настройках доступна кнопка **«Показать сейчас»** для проверки, не дожидаясь таймера.

## Возможности

- **9 бесплатных UHD-клипов (3840×2160)** из четырёх коллекций: **Осень**, **Halloween**, **Неоновый город** и **Камин / уют**.
- Бесконечная автоматическая смена роликов, **случайная** или **по порядку**; можно выбрать одну тему.
- Плавное затухание к чёрному между роликами: **быстро / плавно / очень плавно**.
- **Полная тишина**: видео проигрывается с `muted`, `defaultMuted`, `volume=0`.
- Автоматический запуск после **1 / 3 / 5 / 10 минут** бездействия (по умолчанию 3).
- Нажатие кнопки пульта закрывает заставку благодаря штатному обработчику Lampa.
- При запуске фильма штатный idle-механизм временно отключается; после выхода — восстанавливается.
- Один HTML5-видеодекодер за раз, без параллельного декодирования двух 4K-потоков, чтобы снизить нагрузку на Tizen.
- Настройки сохраняются локально в Lampa.

## Совместимость и ограничения

- Требуется сборка Lampa, в которой доступен `Lampa.Screensaver.class_list` и `Lampa.SettingsApi`.
- **Это HTML5-видеозаставка, не AVPlay.** Разрешение источников подтверждено на страницах Pexels, но воспроизведение в настоящем 4K зависит от поддержки браузерного видеодекодера конкретной модели телевизора, сети и источника. На Samsung The Frame 2022 плагин **ещё нужно проверить непосредственно на ТВ**.
- UHD-файлы большие. Рекомендуется стабильный интернет; автоматического переключения на 1080p в версии 1.0 пока нет.
- Источники хранятся **на Pexels**, а не в репозитории. При блокировке hotlink/ошибке сети или удалении файла ролик пропускается; когда не работает вся подборка, на экране появляется уведомление.
- Для стабильности используется **fade-to-black** (мягкое затемнение), а не аппаратный crossfade двух одновременно играющих UHD-видео.
- Это заставка **внутри Lampa**. Она не заменяет системный экран ожидания Samsung при выходе из приложения или выключении телевизора.

## Обновления

Плагин загружается из ветки `main` через ссылку выше. При изменении JS могут потребоваться перезапуск Lampa и очистка кэша плагинов.

## Проверка при проблемах

1. Убедитесь, что заставка включена в **Настройки → Cinematic Screensaver**.
2. Нажмите **«Показать сейчас»**. Если видео не появляется, проверьте открытие ссылок Pexels на этом устройстве и интернет.
3. Проверьте штатные настройки Lampa для заставки, если другой плагин их меняет.
4. При проблемах напишите модель ТВ, версию Lampa и сообщение консоли Lampa в [Issues](https://github.com/DoubleGGameRR/Lampa-Cinematic-Screensaver/issues).
