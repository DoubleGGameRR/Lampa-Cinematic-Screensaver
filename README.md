# Lampa Cinematic Screensaver — 2.1.0

Атмосферные UHD-видеозаставки Lampa на Samsung Tizen: 21 ролик, настоящее плавное перекрытие видео, часы, дата и погода в Микитинцах.

## Установка и обновление

**Новый URL версии 2.1.0 (не зависит от кэша старого @main):**

```text
https://cdn.jsdelivr.net/gh/DoubleGGameRR/Lampa-Cinematic-Screensaver@21aae462900c7066c80d439d0646166c76f57a93/plugin.js
```

1. Откройте **Lampa → Настройки → Плагины / Расширения**.
2. Если ранее подключали этот скринсейвер, удалите старую ссылку на него (как raw.githubusercontent.com, так и @main). Две версии одновременно подключать не нужно.
3. Добавьте новый URL и полностью перезапустите Lampa.
4. Откройте **Настройки → Cinematic Screensaver → Показать сейчас**.

Для обычных последующих обновлений остаётся ссылка:

```text
https://cdn.jsdelivr.net/gh/DoubleGGameRR/Lampa-Cinematic-Screensaver@main/plugin.js
```

Для Samsung желателен jsDelivr: GitHub Raw иногда раздаёт JavaScript с MIME text/plain и может блокироваться Tizen. @main может кэшироваться, поэтому выше приведён также адрес конкретной версии.

## Возможности

- **21 UHD-ролик**: 9 Halloween, 5 осенних, 4 ночных города, 3 уютных.
- **Тематические главы длиной 5 / 7 / 10 минут**, с автоматической сменой сцен и тем. Важно: это **последовательности отдельных роликов**, а не один 10-минутный видеофайл. Отдельные клипы длятся от нескольких секунд до почти четырёх минут.
- **Настоящий перекрывающий crossfade** вместо чёрного экрана. Следующий файл заранее буферизуется в другом HTML5-видеослое, плавное проявление регулируется: 1,6 / 2,8 / 4 секунды.
- Без звука. Нажатие кнопки пульта закрывает заставку.
- Автоматический запуск после 1 / 3 / 5 / 10 минут бездействия (по умолчанию 3).
- Все темы по кругу, в случайном порядке или только выбранная коллекция.
- Нижний левый угол: **крупное время, дата и текущая погода для Микитинцев (Ивано-Франковская область)**. Время по часовому поясу Europe/Kyiv. Часы обновляются каждые 15 секунд, погода — каждые 20 минут. Информационный блок можно отключить в настройках.
- Использует встроенный механизм Lampa.Screensaver и не вмешивается в просмотр фильма.

## Погода

Данные получаются напрямую с телевизора по бесплатному некоммерческому API [Open-Meteo](https://open-meteo.com/), без регистрации или API-ключа. Координаты Микитинцев (Микитинці): **48.88694, 24.75111**. Данные имеют лицензию CC BY 4.0, источник указан внутри интерфейса. [Условия Open-Meteo](https://open-meteo.com/en/terms).

Если запрос погоды недоступен, время и дата продолжают отображаться. Погода — модельные данные ближайшей ячейки, не индивидуальная метеостанция населённого пункта.

## Важные ограничения

**Два параллельных потока 4K во время crossfade могут оказаться тяжелыми для Samsung The Frame 2022.** Переходы протестированы программно с имитацией HTML5-видеоплеера, но реальное поведение на этом ТВ ещё необходимо проверить. Если два декодера недоступны, возможны паузы, чёрный экран или невоспроизведение следующей сцены. Поддержка UHD зависит от модели, сети и исходных файлов; гарантировать 4K в каждой сборке Lampa нельзя.

Для установки необходимы Lampa.Screensaver.class_list и Lampa.SettingsApi. Некоторые форки Lampa могут быть несовместимы.
